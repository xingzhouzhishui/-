# 晓梦生小手机

为 AIRP 群体打造的模拟手机 Web App，亚系灰萌 + 高质感 iOS 风格，让「手机另一边的 ta」活过来。所有数据本地 `localStorage` 持久化，各应用间互通记忆。

## 运行方法

用 Live Server 打开 `index.html`，或双击在浏览器打开。推荐手机视图（iPhone 尺寸）体验最佳。

## 应用清单

| 应用 | 功能 |
|------|------|
| **微信** | 高拟真会话/通讯录/发现/我；聊天详情支持转账、对话、撤回、修改、重回、红包、照片、语音、位置、语音/视频通话、表情包；群聊模拟；朋友圈；收藏；角色备注/世界书挂载/向量总结/心声状态栏/已读不回/时间感知 |
| **网易云音乐** | 登录网易云账号、本地导入、联网搜索、与 ta 共听 |
| **酒馆** | 线下模式：世界书多选挂载、文风、角色卡、对话生成 |
| **设置** | 多套用户配置、字体/壁纸、AI API、通知、备份导入导出 |
| **角色设定** | 多角色卡，详细人设 + 防串味机制（口吻/禁止提及/负面提示）+ 世界书挂载/常驻 + 线上/线下文风 |
| **世界书** | 纯用户导入（txt/docx/json/md/粘贴），多选载入、是否常驻、优先级规则 |
| **文风** | 线上/线下风格，新建编辑删除 |
| **情侣空间** | 每日日记（即时/定时生成）、情侣任务积分、甜蜜道具兑换 |
| **查看手机** | 查 char 手机 + 反向查 user 手机 |
| **共读** | 生成同人文、导入书本、与 ta 共读 |
| **商城** | 导入 HTML |
| **论坛** | 知乎风格：提问、回答、热门/最新 |

## 架构

- `index.html`：手机外壳（状态栏/桌面/Dock/应用容器）+ 各应用 `<template>`
- `styles.css`：壁纸基调 + 亚系灰萌暗色主题、毛玻璃、iOS 圆角、动效
- `app.js`：应用注册表、导航栈（返回键）、数据层、各模块渲染
- `wallpaper.jpg`：默认壁纸（可设置页替换）

## 数据键

`profiles`（多用户）、`characters`（多角色）、`worldbooks`、`styles`、`chats`/`msg_<id>`、`moments`、`favorites`、`stickers`、`tracks`、`coupleDiary`/`coupleTasks`/`couplePoints`、`books`、`forumPosts`

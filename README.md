亚萌灰色系 模拟手机 原型

说明：
- 本原型为静态前端演示，展示“整体设置”页面功能，包括字体导入、字体大小、API 地址/密钥、壁纸导入、备份导入导出、桌面导入导出等。

运行方法：
直接在浏览器中打开 index.html 即可查看原型。

后续：
我可以继续实现桌面布局、模拟微信聊天及角色管理等功能。

AI 生成支持（新增）:
- 在设置页可输入 API 地址、密钥与模型名称以连接第三方生成服务。
- 新增 "AI 生成（图片 / 语音）" 区块：可输入提示并调用 API 生成内容。
- 生成结果会缓存到本地（`localStorage`），重复播放/查看不会再次调用 API，从而节省配额。
- 若未填写 API 地址，图片生成回退为简单 SVG 占位，语音生成回退为浏览器语音合成（不产生可下载的音频数据）。

使用示例：
1. 在 "API 与模型" 区填写 `API 地址`、`API 密钥` 和 `模型名称`（接口需支持返回 base64 的音频或图片）。
2. 在 "AI 生成" 区填写提示，点击 "生成图片" 或 "生成语音"。
3. 生成后结果会显示在下方列表，可播放或导入到本地聊天消息中。

# 晓梦生小手机

亚萌灰色系风格的手机模拟 Web App，模仿真实手机桌面 + 应用启动器，所有数据本地 `localStorage` 持久化。

## 运行方法

直接用 Live Server 打开 `index.html`（推荐，文件读取与 localStorage 更稳定），或双击 `index.html` 在浏览器打开。

## 已实现的应用

| 应用 | 功能 |
|------|------|
| **微信** | 会话列表、通讯录、发现、我的；进入聊天详情可收发消息、模拟回复 |
| **音乐** | 播放器 UI、旋转唱片、播放/暂停切换 |
| **酒馆** | 世界书挂载、文风选择、角色卡网格、对话生成（模拟） |
| **设置** | 字体/字号/壁纸、API 地址/密钥/模型、通知开关、备份导入导出 |
| **角色设定** | 用户/角色身份与人设编辑、导入导出 JSON |
| **世界书** | 条目 CRUD、关键词、导入 txt/json/docx 文本 |
| **文风管理** | 新建/编辑/删除文风、场景标签、酒馆联动 |
| **情侣空间** | 每日日记、任务打卡 |
| **商城** | HTML 文件导入 |
| **论坛** | 帖子列表（最新/热门/我的） |
| **相册/便签/时钟/电话/邮件/相机** | 占位（开发中） |

## 架构说明

- `index.html`：手机外壳（状态栏、桌面、Dock、应用容器）+ 各应用模板（`<template>`）
- `styles.css`：亚萌灰主题、图标配色、iOS 风格毛玻璃、响应式（≤360/≤480/≥768）
- `app.js`：应用注册表 `APPS`、桌面渲染、导航栈（打开/返回）、各应用渲染函数
- `manifest.json`：PWA 支持，可添加到主屏

## 数据存储键

`settings`（外观/API）、`chats`/`msg_<id>`（微信）、`worldbooks`、`writingStyles`、`tavernChars`、`tavernMessages`、`identity`、`coupleTasks`、`coupleDiary`、`forumPosts`
